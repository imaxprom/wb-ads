# WB Ads

## Проект
- Рабочая директория: `/Users/octopus/Projects/wb-ads`
- Стек: Next.js + TypeScript + Tailwind CSS + SQLite (better-sqlite3) + Puppeteer
- Порт: 3001
- БД: `data/ads.db` (50 таблиц, проверено 26 мая 2026)
- Контекст проекта: `PROJECT_CONTEXT.md`
- База знаний в UI: `src/components/KnowledgeBase.tsx`

## Команды
- `npm run dev` — запуск dev-сервера на порту 3001
- `npm run init-db` — инициализация БД (создание всех таблиц)
- `npm run save-session-state` — обновить `SESSION_STATE.md` из БД и локальных status endpoints

## Правила
- ЗАПРЕЩЕНО обращаться к `/Users/octopus/Projects/website/` или другим проектам без явного разрешения пользователя
- Все зависимости локальные (`npm install` без `-g`)
- Проект полностью автономный, не зависит от MpHub
- Все даты через `localDateStr()` (Москва), НЕ `toISOString()` (UTC)
- Все настройки в БД через API (НЕ localStorage)
- SVG-иконки вместо эмодзи
- Внутренние server-to-server вызовы только через `WB_ADS_INTERNAL_BASE_URL` или `http://127.0.0.1:3001`, НЕ `localhost:3001` (иначе возможен редирект `/login` и пустые `OK 0` в test-auto)

## Стиль ответов (СТРОГО)
- Отвечать **кратко и по делу**. Длинные простыни не нужны — пользователь читает много за день.
- **Без блоков кода** в ответах. Обычный русский текст. Если упомянуть файл/символ/endpoint — одной строкой именем, без форматирования как код.
- Реализация через tool-calls (Edit/Write) — не код «в ответе»: писать файлы можно и нужно, но не дублировать содержимое в тексте.
- Диффы и результаты правок — описывать словами: «изменил X, добавил Y», а не показывать фрагменты.
- Код показывать **только** по явному запросу («покажи код», «напиши функцию», «как это в коде выглядит»).
- Списки — ок, но короткие. Заголовки — только если ответ реально многоразделный.
- ТЗ и план реализации — текстом, без code-блоков с псевдо-схемами.

## Запрет самовольного тестирования mutating API (СТРОГО)
Без явного разрешения пользователя ЗАПРЕЩЕНО вызывать любые WB/cmp API, изменяющие состояние:
- Ставки: `/adv/v0/normquery/bids`, `/adv/v0/cpm`, `/v1/advert/{id}/preset`, `/preset/reset`
- Цены товара (public/cmp price endpoints)
- Исключения фраз: `/adv/v0/normquery/set-minus`, cmp `/preset/minus`
- Добавление/удаление товаров из кампании, запуск/пауза/архивация, бюджеты, placements
- Любые POST/PUT/PATCH/DELETE к `advert-api.wildberries.ru` и `cmp.wildberries.ru`, кроме read-only
- Запрет распространяется на всё: curl, dev-сервер UI, debug-endpoints, «разовую проверку»

Разрешено: **писать код** для mutating API. После реализации — сообщить «готово, жду разрешения на тестирование» и ждать явного «да, тестируй». При любых сомнениях — спросить.

## Сохранение контекста (ОБЯЗАТЕЛЬНО)
- При завершении сессии или по запросу пользователя — ОБЯЗАТЕЛЬНО сохранить:
  0. `SESSION_STATE.md` — коротко обновить текущую точку остановки, фактические статусы и следующий шаг. Сначала запустить `npm run save-session-state`, затем вручную поправить только смысловые блоки, если менялась цель/следующий шаг
  1. `PROJECT_CONTEXT.md` — обновить если были изменения в архитектуре, таблицах, формулах, sync
  2. Память Codex (`~/.codex/memories/`) — обновить актуальные project/session notes. Старую Claude-память можно читать как справочник, но не считать источником истины без сверки с кодом и БД
  3. `KnowledgeBase.tsx` — обновить если менялись столбцы, таблицы, формулы, настройки
- Если сессия длится больше 1 часа — промежуточное сохранение контекста
- Если пользователь говорит "запиши", "сохрани", "запомни" — немедленно сохранить в память
- При сохранении — НЕ использовать кэш, перечитывать код заново и сверять с реальным состоянием
